## Product

## Locked decisions

## Gotchas learned (save yourself the time)
- Pest: JSON tests only send cookies after `->withCredentials()`; `withToken()` persists across requests in one test (use `->withoutToken()`); the JWT guard remembers the last user, so call `app('auth')->forgetGuards()` between requests as different users; roles live on guard `api` and the role middleware syntax is `role:admin|super_admin,api`; `make:test --pest Auth/FooTest` (do NOT prefix `Feature/`, it doubles); `make:enum` lands in `app/`, move it to `app/Enums`; after `migrate:fresh` run `db:seed` or roles are missing.
- A JWT carries roles from login time: after something changes roles (e.g. provider registration) the SPA must call `refreshSession()`.
- Vitest: MSW is v3 (`onUnhandledFrame`, not `onUnhandledRequest`), jsdom URL is `http://localhost`, `asyncUtilTimeout` is 4s in `resources/js/test/setup.ts`; unmount (`cleanup()`) before clearing the auth store in `afterEach`; use `renderWithProviders` from `resources/js/test/render.tsx`. Never run `pkill -f vitest` in the same command as vitest (it kills your own shell); use a bracketed pattern like `pkill -f "[v]itest"`.
- shadcn CLI: it generates `import { cn } from "cn"` (an unrelated npm package); fix imports to `@/lib/utils`. `shadcn add --overwrite` resets `button.tsx` (our `loading` prop and `lg` size must be re-applied). Do not add `next-themes`.
- Scripted edits to prettier-formatted files can silently not match; re-read the file after editing routes. A missing route caused an infinite `/admin` ↔ `/login` redirect that hung Vitest.
- Playwright: `npm run build`, then `npm run e2e:serve` (serves with `APP_ENV=e2e`, which loads the full-copy `.env.e2e` with `AUTH_RATE_LIMIT=1000`; `artisan serve` ignores other env overrides and uses the dev SQLite DB). Seed an admin first: `php artisan app:create-admin e2e-admin@example.com --name="E2E Admin" --password='Password123!'`. Locators are strict: `getByLabel('Email')` also matches "Support email", `getByRole('button',{name:'Activate'})` also matches "Deactivate"; use `exact: true` or scope to a row/dialog. Wait for the next page's heading before filling a form after a navigation. Run specs serially (config pins one worker). Clean the dev DB afterwards with `php artisan migrate:fresh --seed --force`.
